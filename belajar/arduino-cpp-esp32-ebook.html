1. Pengenalan C++ dan Struktur Program

Sebelum memprogram Arduino/ESP32, Anda perlu memahami dasar-dasar C++. Bahasa C++ adalah bahasa pemrograman yang mendukung pemrograman berorientasi objek dan digunakan secara luas dalam pengembangan sistem embedded seperti Arduino.

1.1 Program C++ Paling Sederhana

Contoh 1.1: Program "Hello World" dalam C++ Contoh 1
#include <iostream>
using namespace std;

int main() { cout << "Hello World"; return 0; }

Penjelasan Baris per Baris:

  • #include <iostream> : Preprocessor directive untuk menyertakan library input-output standar C++. Tanpa ini, Anda tidak bisa menggunakan cout dan cin.
  • using namespace std; : Deklarasi untuk menggunakan namespace standard, sehingga tidak perlu menulis std::cout cukup cout saja.
  • int main() { ... } : Fungsi utama program C++. Setiap program C++ HARUS memiliki fungsi main() sebagai titik masuk eksekusi.
  • cout << "Hello World"; : Perintah untuk menampilkan teks "Hello World" ke layar (console output).
  • return 0; : Mengembalikan nilai 0 yang menandakan program berakhir dengan sukses.

1.2 Struktur Program Arduino/ESP32

Program Arduino/ESP32 memiliki struktur khusus yang berbeda dari program C++ standar:

Contoh 1.2: Struktur Dasar Program Arduino/ESP32 Contoh 2
// 1. Library (paling atas) #include <Arduino.h> // Library tambahan jika diperlukan #include <WiFi.h> #include <DHT.h>
// 2. Variabel global (setelah library, sebelum setup()) int ledPin = 2; unsigned long lastTime = 0;
// 3. Fungsi setup() - dijalankan sekali saat startup void setup() { Serial.begin(115200); pinMode(ledPin, OUTPUT); }
// 4. Fungsi loop() - dijalankan berulang selamanya void loop() { digitalWrite(ledPin, HIGH); delay(1000); digitalWrite(ledPin, LOW); delay(1000); }

Analogi untuk Memahami Struktur:

Bayangkan Anda memprogram sebuah robot kecil:

  • #include = Memberi tahu robot "peralatan" apa yang akan digunakan
  • Variabel global = Catatan yang selalu tersedia selama robot hidup
  • setup() = Persiapan awal robot (sekali saat dinyalakan)
  • loop() = Perilaku berulang robot selama hidupnya

2.2 Kenapa unsigned long untuk millis()?

PENTING: Fungsi millis() pada Arduino mengembalikan nilai unsigned long (0 hingga 4,294,967,295) yang mewakili milidetik sejak Arduino dinyalakan. Setelah sekitar 49.7 hari, nilai ini akan reset ke 0 (overflow). Menggunakan int akan menyebabkan kesalahan setelah 32,767 milidetik (32.7 detik)!
Contoh 2.2: Penggunaan millis() yang Benar Contoh 4
// Contoh timer menggunakan millis() tanpa delay() unsigned long previousMillis = 0; // harus unsigned long const long interval = 1000; // interval 1 detik int ledState = LOW; // status LED
void setup() { pinMode(LED_BUILTIN, OUTPUT); }
void loop() { unsigned long currentMillis = millis(); // ambil waktu sekarang
// Cek jika sudah melewati interval if (currentMillis - previousMillis >= interval) { previousMillis = currentMillis; // simpan waktu terakhir
// Toggle LED if (ledState == LOW) { ledState = HIGH; } else { ledState = LOW; } digitalWrite(LED_BUILTIN, ledState); }
// Di sini bisa menambah kode lain yang berjalan tanpa delay }

Kenapa lebih baik daripada delay()?

delay() menghentikan seluruh program, sedangkan metode dengan millis() memungkinkan program melakukan tugas lain sambil menunggu waktu tertentu.

3. Kontrol Alur Program

Kontrol alur menentukan urutan eksekusi perintah dalam program. Ada tiga jenis utama: percabangan (if-else, switch), pengulangan (for, while, do-while), dan lompatan (break, continue, return).

3.1 Percabangan: if, else if, else

Contoh 3.1: Percabangan if-else untuk Membaca Sensor Contoh 5
// Contoh membaca sensor suhu dan menentukan status float suhu = readTemperature(); // fungsi baca sensor
if (suhu < 20) { Serial.println("Suhu dingin"); digitalWrite(HEATER_PIN, HIGH); // nyalakan pemanas } else if (suhu >= 20 && suhu <= 30) { Serial.println("Suhu normal"); digitalWrite(HEATER_PIN, LOW); // matikan pemanas } else { Serial.println("Suhu panas"); digitalWrite(COOLER_PIN, HIGH); // nyalakan pendingin }

3.2 Percabangan: switch-case

Contoh 3.2: switch-case untuk Menu Pilihan Contoh 6
// Contoh menu pilihan dari input serial char pilihan = Serial.read(); // baca input dari serial
switch (pilihan) { case '1': Serial.println("Mode 1: Baca sensor"); modeBacaSensor(); break;
case '2': Serial.println("Mode 2: Kontrol LED"); modeKontrolLED(); break;
case '3': Serial.println("Mode 3: Set WiFi"); modeSetWiFi(); break;
default: Serial.println("Pilihan tidak valid"); break; }

3.3 Pengulangan: for, while, do-while

Contoh 3.3: Tiga Jenis Loop untuk Kontrol LED Contoh 7
// 1. for loop - diketahui berapa kali pengulangan // LED blink 10 kali for (int i = 0; i < 10; i++) { digitalWrite(LED_PIN, HIGH); delay(500); digitalWrite(LED_PIN, LOW); delay(500); }
// 2. while loop - selama kondisi benar // Tunggu sampai tombol ditekan bool tombolDitekan = false; while (!tombolDitekan) { tombolDitekan = digitalRead(BUTTON_PIN); delay(10); // debounce kecil }
// 3. do-while loop - jalankan minimal sekali // Kalibrasi sensor minimal sekali int nilaiKalibrasi; do { nilaiKalibrasi = bacaSensor(); Serial.println("Mengkalibrasi..."); delay(1000); } while (nilaiKalibrasi == 0); // ulangi jika nilai 0

4. Fungsi dalam C++

Fungsi adalah blok kode yang memiliki nama dan dapat dipanggil berkali-kali. Fungsi membuat kode lebih terorganisir, mudah dibaca, dan dapat digunakan kembali.

4.1 Struktur Fungsi

Contoh 4.1: Membuat dan Memanggil Fungsi Contoh 8
// Deklarasi fungsi (prototype) - opsional jika fungsi didefinisikan sebelum dipanggil int tambah(int a, int b); void blinkLED(int pin, int delayTime);
void setup() { Serial.begin(115200);
// Memanggil fungsi tambah int hasil = tambah(5, 3); Serial.print("Hasil penjumlahan: "); Serial.println(hasil);
// Memanggil fungsi blinkLED blinkLED(LED_BUILTIN, 500); }
// Definisi fungsi tambah int tambah(int a, int b) { return a + b; // mengembalikan nilai }
// Definisi fungsi blinkLED void blinkLED(int pin, int delayTime) { digitalWrite(pin, HIGH); delay(delayTime); digitalWrite(pin, LOW); delay(delayTime); }
void loop() { // loop kosong atau berisi kode lain }

Komponen Fungsi:

  1. Tipe return: int, void, float, dll. void berarti tidak mengembalikan nilai.
  2. Nama fungsi: Nama yang deskriptif untuk fungsi.
  3. Parameter: Variabel input fungsi (bisa kosong).
  4. Body fungsi: Blok kode dalam { } yang akan dieksekusi.
  5. Return statement: Mengembalikan nilai (kecuali tipe void).

4.2 Fungsi Khusus Arduino: setup() dan loop()

PENTING DIPAHAMI: Arduino IDE secara otomatis menambahkan prototipe untuk setup() dan loop(). Inilah sebabnya Anda tidak perlu mendeklarasikannya secara manual. Arduino runtime akan memanggil setup() sekali saat startup, kemudian memanggil loop() berulang-ulang selamanya.

4.3 Penjelasan static, void, dan public

Contoh 4.2: Penjelasan Keyword Penting Penjelasan Detail

Apa itu static?

static memiliki dua makna tergantung konteks:

// 1. Static dalam variabel lokal fungsi void hitungPanggilan() { static int counter = 0; // Hanya diinisialisasi sekali counter++; Serial.print("Fungsi dipanggil: "); Serial.println(counter); } // Setiap panggilan akan increment counter, tidak reset ke 0
// 2. Static dalam class (akan dibahas di bagian OOP) class Sensor { static int jumlahSensor; // Dapat diakses tanpa instance class };

Apa itu void?

void berarti "kosong" atau "tidak ada". Digunakan untuk:

  • Fungsi yang tidak mengembalikan nilai: void setup() { ... }
  • Fungsi yang tidak menerima parameter: int getValue(void) { ... }
  • Pointer ke tipe data tidak tertentu: void* ptr;

Apa itu public?

public adalah access modifier dalam pemrograman berorientasi objek (OOP) yang menentukan bahwa anggota class dapat diakses dari luar class.

class LED { public: // Bagian yang dapat diakses dari luar class void nyala() { digitalWrite(pin, HIGH); }
private: // Bagian yang hanya dapat diakses dari dalam class int pin = 2; };
// Penggunaan LED ledKu; ledKu.nyala(); // BISA: fungsi public // ledKu.pin = 3; // ERROR: variabel private

5. Array dan String

5.1 Array: Kumpulan Data Bertipe Sama

Contoh 5.1: Array untuk Menyimpan Data Sensor Contoh 9
// Array untuk menyimpan 5 pembacaan sensor terakhir int sensorReadings[5]; // Deklarasi array 5 elemen int readingIndex = 0;
void setup() { Serial.begin(115200);
// Inisialisasi array for (int i = 0; i < 5; i++) { sensorReadings[i] = 0; } }
void loop() { // Simpan pembacaan sensor ke array sensorReadings[readingIndex] = analogRead(SENSOR_PIN);
// Hitung rata-rata int total = 0; for (int i = 0; i < 5; i++) { total += sensorReadings[i]; } float rataRata = total / 5.0;
Serial.print("Rata-rata: "); Serial.println(rataRata);
// Update index untuk pembacaan berikutnya readingIndex = (readingIndex + 1) % 5; // 0,1,2,3,4,0,1,...
delay(1000); }

Catatan Penting tentang Array:

  • Index array selalu dimulai dari 0
  • Array diakses dengan notasi bracket: array[index]
  • Ukuran array harus diketahui saat kompilasi (kecuali dynamic array)
  • Array tidak mengecek batas (bound checking) - hati-hati dengan buffer overflow!

5.2 String: Teks dalam C++

Contoh 5.2: Manipulasi String untuk Pesan Serial Contoh 10
// Contoh penggunaan String (object) vs string (array char)
// 1. String object (lebih mudah, tapi gunakan lebih banyak memori) void setup() { Serial.begin(115200);
String pesan = "Suhu: "; float suhu = 25.5;
// Konkatenasi (penggabungan) string pesan += suhu; pesan += "°C";
Serial.println(pesan); // Output: "Suhu: 25.50°C"
// Metode String yang berguna Serial.println(pesan.length()); // Panjang string Serial.println(pesan.substring(0, 5)); // "Suhu:" Serial.println(pesan.indexOf("°C")); // Posisi "°C" }
// 2. Array char (C-style string, hemat memori) void cStyleString() { char buffer[50]; // Buffer untuk string int nilai = 42;
// sprintf untuk format string seperti di C sprintf(buffer, "Nilai: %d, Float: %.2f", nilai, 3.14159); Serial.println(buffer); // Output: "Nilai: 42, Float: 3.14" }
PERINGATAN: Hindari menggunakan String object pada Arduino jika memori terbatas atau dalam fungsi yang sering dipanggil. String object dapat menyebabkan fragmentasi heap memory. Gunakan array char untuk kode yang lebih stabil.

6. Struktur Program Arduino/ESP32

Setelah memahami dasar C++, sekarang kita fokus pada struktur khusus Arduino/ESP32. Berdasarkan referensi resmi Arduino, program Arduino dapat dibagi menjadi tiga bagian utama: functions, values (variables and constants), dan structure.

6.1 Pola Umum Program Arduino/ESP32

Contoh 6.1: Pola Lengkap Program Arduino/ESP32 Contoh 11
// ============================================= // BAGIAN 1: LIBRARY (paling atas) // ============================================= #include <Arduino.h> // Core Arduino (otomatis di Arduino IDE) #include <WiFi.h> // Untuk ESP32 WiFi #include <SPI.h> // Untuk komunikasi SPI // Tambahan library sesuai kebutuhan
// ============================================= // BAGIAN 2: DEFINISI DAN DEKLARASI // ============================================= // 2.1 Konstanta (tidak berubah) #define LED_PIN 2 // Direktif preprocessor const int BUTTON_PIN = 4; // Konstanta C++ const long BAUD_RATE = 115200;
// 2.2 Variabel global (dapat diubah) int counter = 0; // Counter sederhana unsigned long lastMillis = 0; // Untuk timer float sensorValue = 0.0; // Nilai sensor bool systemStatus = false; // Status sistem
// 2.3 Deklarasi fungsi (jika fungsi didefinisikan setelah loop) void connectToWiFi(); int readSensor(int pin); void handleButtonPress();
// ============================================= // BAGIAN 3: SETUP() - dijalankan sekali // ============================================= void setup() { // 3.1 Inisialisasi komunikasi serial Serial.begin(BAUD_RATE); delay(100); // Tunggu stabil Serial.println("System starting...");
// 3.2 Konfigurasi pin pinMode(LED_PIN, OUTPUT); pinMode(BUTTON_PIN, INPUT_PULLUP);
// 3.3 Inisialisasi sistem lain connectToWiFi();
// 3.4 Status awal digitalWrite(LED_PIN, HIGH); // LED nyala saat startup delay(500); digitalWrite(LED_PIN, LOW); // LED mati
Serial.println("Setup completed!"); }
// ============================================= // BAGIAN 4: LOOP() - dijalankan terus menerus // ============================================= void loop() { // 4.1 Baca input sensorValue = readSensor(A0); handleButtonPress();
// 4.2 Proses data if (sensorValue > 100) { digitalWrite(LED_PIN, HIGH); } else { digitalWrite(LED_PIN, LOW); }
// 4.3 Timer-based task (tanpa delay) unsigned long currentMillis = millis(); if (currentMillis - lastMillis >= 5000) { // Setiap 5 detik lastMillis = currentMillis; Serial.print("Sensor: "); Serial.println(sensorValue); counter++; }
// 4.4 Delay kecil untuk mengurangi CPU usage delay(10); }
// ============================================= // BAGIAN 5: DEFINISI FUNGSI LAIN // ============================================= void connectToWiFi() { // Implementasi koneksi WiFi Serial.println("Connecting to WiFi..."); // ... kode WiFi ... }
int readSensor(int pin) { return analogRead(pin); }
void handleButtonPress() { if (digitalRead(BUTTON_PIN) == LOW) { delay(50); // Debounce if (digitalRead(BUTTON_PIN) == LOW) { Serial.println("Button pressed!"); } } }

Analogi untuk Memahami Struktur:

Bayangkan Anda memprogram sebuah pabrik otomatis:

  • #include = Memesan mesin dan alat yang dibutuhkan
  • Konstanta/Variabel = Pengaturan awal pabrik (jadwal, target produksi)
  • setup() = Persiapan awal pabrik (nyalakan mesin, tes sistem)
  • loop() = Proses produksi yang berjalan terus menerus
  • Fungsi lain = Departemen khusus (quality control, packaging, dll.)

6.2 Jawaban untuk Pertanyaan Umum Pemula

Q: Dari mana fungsi seperti pinMode, digitalWrite, Serial.begin berasal?

A: Fungsi-fungsi ini didefinisikan dalam Arduino Core Library. Ketika Anda menginstal Arduino IDE, library ini sudah termasuk. Untuk ESP32, ada ESP32 Arduino Core yang memberikan fungsi serupa plus fungsi khusus ESP32.

Q: Mengapa tidak perlu menulis #include <Arduino.h> di Arduino IDE?

A: Arduino IDE secara otomatis menambahkan baris ini sebelum kompilasi. Namun di platform lain (PlatformIO, VS Code), Anda mungkin perlu menambahkannya secara manual.

Q: Apa itu Serial dan mengapa penting?

A: Serial adalah objek untuk komunikasi serial antara Arduino/ESP32 dan komputer. Ini adalah "jendela" untuk debugging dan monitoring. Tanpa Serial, Anda tidak bisa melihat apa yang terjadi di dalam mikrokontroler.

7. Library dan Header File

Library adalah kumpulan kode yang sudah jadi yang dapat Anda gunakan kembali. Arduino memiliki ekosistem library yang sangat besar untuk berbagai sensor, modul, dan fungsi.

7.1 Apa itu Library?

Library terdiri dari dua jenis file utama:

  1. Header file (.h): Deklarasi fungsi, class, dan konstanta
  2. Source file (.cpp): Implementasi fungsi
Contoh 7.1: Struktur Library Sederhana Contoh 12
// File: SimpleLED.h (HEADER FILE - deklarasi) #ifndef SimpleLED_h // Include guard - mencegah multiple inclusion #define SimpleLED_h
#include <Arduino.h>
class SimpleLED { public: SimpleLED(int pin); // Constructor void begin(); // Inisialisasi void on(); // Nyalakan LED void off(); // Matikan LED void blink(int delayTime); // LED blink
private: int _pin; // Pin LED bool _state; // Status LED };
#endif // SimpleLED_h

// File: SimpleLED.cpp (SOURCE FILE - implementasi) #include "SimpleLED.h"
// Constructor SimpleLED::SimpleLED(int pin) { _pin = pin; _state = LOW; }
// Inisialisasi void SimpleLED::begin() { pinMode(_pin, OUTPUT); digitalWrite(_pin, LOW); }
// Nyalakan LED void SimpleLED::on() { _state = HIGH; digitalWrite(_pin, HIGH); }
// Matikan LED void SimpleLED::off() { _state = LOW; digitalWrite(_pin, LOW); }
// LED blink void SimpleLED::blink(int delayTime) { this->on(); delay(delayTime); this->off(); delay(delayTime); }

Cara menggunakan library:

// File sketch Arduino utama #include "SimpleLED.h"
// Buat objek LED di pin 2 SimpleLED led(2);
void setup() { led.begin(); // Inisialisasi }
void loop() { led.blink(500); // LED blink setiap 500ms }

8. GPIO dan Digital I/O

GPIO (General Purpose Input/Output) adalah pin yang dapat dikonfigurasi sebagai input atau output. Ini adalah cara utama Arduino/ESP32 berinteraksi dengan dunia luar.

8.1 Fungsi GPIO Dasar

Contoh 8.1: Kontrol LED dan Baca Tombol Contoh 13
// Kontrol LED dan baca tombol (dengan internal pull-up) const int LED_PIN = 2; // LED di pin 2 const int BUTTON_PIN = 4; // Tombol di pin 4
void setup() { Serial.begin(115200);
// Konfigurasi pin pinMode(LED_PIN, OUTPUT); // Pin 2 sebagai OUTPUT pinMode(BUTTON_PIN, INPUT_PULLUP); // Pin 4 sebagai INPUT dengan pull-up internal
Serial.println("GPIO Example Ready"); }
void loop() { // Baca status tombol (LOW ketika ditekan karena pull-up) bool buttonState = digitalRead(BUTTON_PIN);
// Jika tombol ditekan (LOW), nyalakan LED if (buttonState == LOW) { digitalWrite(LED_PIN, HIGH); Serial.println("Button pressed - LED ON"); delay(50); // Debounce delay } else { digitalWrite(LED_PIN, LOW); }
delay(10); // Delay kecil untuk mengurangi CPU usage }

Penjelasan Mode Pin:

  • INPUT: Pin sebagai input (membaca sinyal)
  • OUTPUT: Pin sebagai output (mengirim sinyal)
  • INPUT_PULLUP: Input dengan resistor pull-up internal (HIGH ketika tidak terhubung)
  • INPUT_PULLDOWN: Hanya di ESP32, input dengan resistor pull-down internal

8.2 Multiple LED Control dengan Array

Contoh 8.2: Kontrol 8 LED dengan Array dan Loop Contoh 14
// Kontrol 8 LED secara berurutan (LED chaser) const int NUM_LEDS = 8; int ledPins[NUM_LEDS] = {2, 3, 4, 5, 6, 7, 8, 9};
void setup() { Serial.begin(115200);
// Inisialisasi semua LED pin sebagai OUTPUT for (int i = 0; i < NUM_LEDS; i++) { pinMode(ledPins[i], OUTPUT); digitalWrite(ledPins[i], LOW); // Pastikan semua mati awalnya }
Serial.print("Initialized "); Serial.print(NUM_LEDS); Serial.println(" LEDs"); }
void loop() { // Mode 1: LED berjalan dari kiri ke kanan Serial.println("Mode 1: Left to Right"); for (int i = 0; i < NUM_LEDS; i++) { turnOnOnly(i); // Nyalakan hanya LED ke-i delay(200); }
// Mode 2: LED berjalan dari kanan ke kiri Serial.println("Mode 2: Right to Left"); for (int i = NUM_LEDS - 1; i >= 0; i--) { turnOnOnly(i); delay(200); }
// Mode 3: LED menyala semua berurutan, lalu mati berurutan Serial.println("Mode 3: Sequential On/Off"); for (int i = 0; i < NUM_LEDS; i++) { digitalWrite(ledPins[i], HIGH); delay(100); }
for (int i = 0; i < NUM_LEDS; i++) { digitalWrite(ledPins[i], LOW); delay(100); }
delay(1000); // Jeda antar pola }
// Fungsi untuk menyalakan hanya satu LED, matikan yang lain void turnOnOnly(int index) { // Matikan semua LED terlebih dahulu for (int i = 0; i < NUM_LEDS; i++) { digitalWrite(ledPins[i], LOW); }
// Nyalakan LED yang diinginkan digitalWrite(ledPins[index], HIGH); }

Contoh 9.1: Membaca Potensiometer dan Menampilkan Nilai Contoh 15
// Membaca potensiometer dan menampilkan nilainya const int POT_PIN = A0; // Potensiometer di pin analog A0 const int LED_PIN = 9; // LED di pin PWM

16.1 Istilah-Istilah Penting yang Sering Ditanyakan

Istilah Penjelasan Contoh Penggunaan
static Variabel yang mempertahankan nilainya antar pemanggilan fungsi, atau anggota class yang dimiliki class bukan instance. static int counter = 0;
void Tipe data yang berarti "tidak ada nilai". Digunakan untuk fungsi yang tidak mengembalikan nilai. void setup() { }

16.2 FAQ (Frequently Asked Questions)

Q: Mengapa program Arduino tidak punya fungsi main()?

A: Arduino IDE menyembunyikan fungsi main() yang sebenarnya. Di belakang layar, Arduino runtime menyediakan main() yang memanggil setup() sekali, kemudian loop() berulang-ulang.

Q: Apa perbedaan antara #define dan const?

A: #define adalah preprocessor directive (diproses sebelum kompilasi), sedangkan const adalah deklarasi variabel konstan yang diproses saat kompilasi. const lebih type-safe dan direkomendasikan untuk C++.

Q: Kapan menggunakan unsigned long vs long?

A: Gunakan unsigned long untuk nilai yang selalu positif (seperti waktu dari millis()). Gunakan long jika nilai bisa negatif. unsigned long memiliki range 0-4,294,967,295 sedangkan long memiliki range -2,147,483,648 hingga 2,147,483,647.

Q: Mengapa kadang-kadang perlu menambahkan #include <Arduino.h>?

A: Di Arduino IDE, ini otomatis ditambahkan. Namun di platform lain seperti PlatformIO atau saat menggunakan compiler C++ langsung, Anda perlu menambahkannya secara manual untuk mengakses fungsi Arduino seperti pinMode(), digitalWrite(), dll.
