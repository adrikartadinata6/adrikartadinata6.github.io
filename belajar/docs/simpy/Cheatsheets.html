Cheatsheets¶

If you want to have a list of all SimPy commands, their syntax and parameters for your desktop, print out a copy of the SimPy Cheatsheet, or better yet bookmark them in your favorite browser.

The Cheatsheet comes in the following formats:

Traditional API:

  • Excel A4 page

  • Excel Letter page

  • PDF A4 page

  • PDF Letter page

Object Oriented API (new in SimPy 2.0):

  • OO Excel A4 page

  • OO Excel Letter page

  • OO PDF A4 page

  • OO PDF Letter page
