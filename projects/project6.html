Automation Prototype Control Panels

R&D / Automation Nov 2025 s.d. Jan 2026 R&D Electrical Engineer

Conducted feasibility studies for industrial automation prototypes and assembled prototype control panels integrating contactors, relay logic modules, inverters, and PLC I/O wiring to IEC/PUIL standards.

Overview

Project Overview

Background / Problem Statement

Before committing to full industrial automation builds, PT Aldzama needed feasibility studies and working prototype control panels to validate design choices against IEC/PUIL standards.

Project Objectives

Validate automation prototype feasibility, assemble compliant control panels, and support instrumentation design reviews and field installation for control and hydraulic systems.

Main Idea / System Concept

Prototype control panels integrating contactors, relay logic modules, inverters, and PLC I/O wiring, assembled and wired to IEC/PUIL standards ahead of full-scale deployment.

Application / Use Case

Early-stage R&D support for PT Aldzama's industrial automation, control, and hydraulic systems projects.

Technical Details

Technical Details

Panels were assembled around standard industrial control building blocks — contactors, relays, inverters and PLC I/O — then wired and reviewed against IEC/PUIL standards before being handed off for field installation support.
